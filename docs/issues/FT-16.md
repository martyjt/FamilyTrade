## Scope

- Provide versioned Docker Compose configuration for application, workers, PostgreSQL and the supported gateway arrangement proven in FT-03.
- Use a named PostgreSQL volume, persistent per-user archive/report directories, read-only archive mounts for research where applicable, and secrets outside images/Git.
- Configure HTTPS, private database access, restart/health policies, research resource limits, log retention and disk/feed/job alerts.
- Document encrypted off-server database-aware backups, archive/catalog consistency, restoration and update/rollback steps.
- Record the actual Netcup plan/location and measured resource use; no provider-agnostic infrastructure framework.

## Acceptance criteria

- [ ] Application replacement preserves database/archive state; public access exposes only intended authenticated endpoints.
- [ ] A clean restore recovers users, strategy versions, pinned data and run/lane state with documented recovery point/time.
- [ ] Gateway reauthentication/reconnect steps are tested and documented without claiming unsupported headless operation.
- [ ] Research load does not starve feed ingestion and job status; disk/backup failures are visible.
- [ ] Deployment, DNS changes, paid storage and monitoring destinations require the explicit authority supplied to that session; missing authority remains an unmet external criterion.

## Validation

Compose/config checks, clean-host deployment when authorised, restore drill, service restart and a representative ingestion-plus-backtest resource measurement.

## Exclusions

Kubernetes, multi-host high availability, automated purchases, live-order permissions and pretending local containers prove VPS acceptance.

ingestion, workers, gateway, database, proxy, shared networks or volumes. FT-18
(https://github.com/martyjt/FamilyTrade/issues/19) owns prewarm/cutover/drain tooling, release probes and measured rollback
acceptance; keep FT-16 focused on host packaging, backups and restore evidence.

separately and must not be represented as a routine seconds-level app release.
